Orca 화면 수동 형광펜 (실험적)

자동 UI 인식이 아닙니다. 화면 좌표(x, y, 너비, 높이)를 직접 입력하세요. 클릭은 통과합니다.

프로젝트 등록·Worktree·터미널 분할·에이전트 실행 단계는 Orca CLI로 자동 확인해 저절로 넘어갑니다. 나머지 단계는 직접 확인한 뒤 ‘완료했어요’를 누르세요(Alt+→ / Alt+←로 이동). Orca 버튼 형광펜은 Windows에서만 자동입니다.
